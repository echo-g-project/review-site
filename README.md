# ECHO-G supplementary project materials

This snapshot contains the project webpage, demonstration videos, benchmark tables, and architecture figure accompanying the manuscript.

Open `index.html` through the anonymized website view. `static.html` provides a no-JavaScript alternative with native video controls. All media and styles are bundled locally; no public project page or external video host is needed.

## Contents

- Main presentation video (180.26 seconds).
- Fifteen additional real-robot videos, in the supplied numeric order.
- A synchronized conditioning comparison and the three individual condition videos.
- Two benchmark tables and their original images.
- Architecture figure and manuscript abstract.

Paper, code and dataset buttons remain disabled until reviewed resources are supplied. This repository is a demonstration website, not the model implementation or training dataset.

## Media

The main presentation has a lower-bitrate web copy. Its duration, frame rate, resolution, and audio track are preserved; it is not retimed or trimmed. Other video streams are copied without re-encoding. Existing edits already present in the input snapshot are preserved. The two HTML tables retain the supplied numeric values and displayed-precision tie convention.

The webpage uses local files only. The fallback page has no JavaScript dependency. Access to the anonymized webpage and all videos should be tested after hosting; this local snapshot does not itself create an anonymous URL.
